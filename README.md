# Strix Personal — private channel

This is the **access-gated** distribution of the `strix-personal` Claude Code
plugin. The plugin is MIT/open; this repo gates *who gets the curated /
early-access channel* (collaborator or deploy-token access required to clone).

## Install

```
/plugin marketplace add Velarisgroup/Strixgov
/plugin install strix-personal@strix-private
```

Runtime entitlement (Free / Personal / Builder / Team) is still determined by
your `STRIX_API_KEY` at connect time — this repo only controls install access.

Pinned plugin version: **0.1.0**. Built by
`scripts/build_strix_personal_private_dist.py`; do not hand-edit.
